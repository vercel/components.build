Modern web applications are built on reusable UI components, and how we design, build, and share them matters. This specification establishes a formal, open standard for building composable, accessible UI components.

It is co-authored by <Author name="Hayden Bleasel" image="https://github.com/haydenbleasel.png" href="https://x.com/haydenbleasel" /> and <Author name="shadcn" image="https://github.com/shadcn.png" href="https://x.com/shadcn" />, with contributions from the open-source community and informed by popular projects in the React ecosystem.

## What is this specification?

This spec is not a tutorial or course on React, nor a promotion for any specific component library. Instead, it provides high-level guidelines, best practices, and a shared vocabulary for designing UI components that integrate smoothly into any codebase.

## Who is this for?

We're writing this for open-source maintainers and experienced front-end engineers who build and distribute component libraries or design systems. We assume familiarity with JavaScript/TypeScript and React.

All examples use React (with JSX/TSX) for concreteness, but the underlying principles of composition, accessibility, and maintainability apply equally to frameworks like Vue, Svelte, or Angular.
